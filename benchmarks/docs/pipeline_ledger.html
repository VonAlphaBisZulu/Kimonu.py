Orientation

How the pipeline is shaped

Five stages run strictly in sequence, and each consumes only the previous stage's output. That matters for the roadmap: a defect at stage 2 invalidates stages 3 and 4 regardless of whether those stages are themselves correct. Concordance is a fixed input to the kinetic stage in the published formulation — it is computed once and never revised.

Stage 2

Concordance

final rerun: identical on 6 of 11 (one after retest), 5 running
Definition
Complexes i, j are concordant when rows i, j of M = A·K are proportional.
Numbers
n_concordance_modules (non-singleton classes), n_concordant_pairs
Used for
Reported, and it is the sole input to stage 3. Errors here propagate everywhere downstream.
Reference defects
Five, all in find_concordant_complexes.m. A fifth, found on iIT341 on 22 Sep: the Charnes–Cooper scaling variable is capped at 999, so a complex whose activity never exceeds 1/999 cannot reach the normalisation and every pair with it is rejected (198 such complexes on iIT341, 196 on iLJ478, 183 on iSB619, 69 on iNF517, none on the others). Fixed on the fork by bounding t per denominator at 999 / max|Aj·v|; re-testing the 1300 rejected iIT341 pairs recovers 1286, and the resulting partition equals Kimonu's exactly (14 residual pairs lie inside modules already joined by others). The first four: unswapped flux bounds in the negative Charnes-Cooper branch; the scaling variable left in the objective ([-A_i 1] where α = 0), which collapses the reported ratio range toward zero by up to six orders of magnitude; round(x,2) equality as an absolute 5×10⁻³ tolerance; and an infeasible branch injecting ±Inf that vetoes a clean one.
Validated
With all three fixes, the reference reproduces Kimonu's concordance partition exactly on two full models: iIS312_Trypomastigote 111/111 classes and iIS312_Amastigote 165/165, zero differences either way, balanced counts matching. Unfixed it gave 109 and 161.
Outstanding
Superseded by the final rerun on the fixed algorithm and fixed bridge. Exhaustive: identical to Kimonu on iIS312, its three life-stage models and iCN900; iIT341 identical after re-testing its rejected pairs with the scaling-bound fix (policy for the remaining runs: re-test rejected pairs only, acceptances are already a verified subset). iJB785, iLJ478, Saha2011iRS1597, iNF517, iSB619 running, 4 days in. Sampled: complete on all 11 at 3 seeds, balanced identical and concordant pairs a strict subset of Kimonu's on every cell (never a superset).
Stage 3

Kinetic modules · the Upstream Algorithm

upstream sets identical on 33 / 33; only the merge rule differs
Numbers
n_kinetic_modules, giant_kinetic_module, n_sccs, largest_scc, n_terminal_sccs, deficiency, kinetic_iterations
Used for
The giant is the headline figure in the reference's Table S1 and in COCOA's Supplementary Figures 1 and 2. It is also the number this project has most often mis-stated.

Langary et al. publish two algorithms. §S.2.2 gives a four-phase version explicitly framed as scaffolding — "we take baby steps". Remark S2-1 then gives the simplified version and names it the Upstream Algorithm.

Phase I
Exclude entry complexes, to a fixed point
A complex with an incoming reaction from outside 𝒞₀. Buys autonomy. Present in both versions.
Phase II
Exclude non-reactant complexes
Only incoming, no outgoing reactions anywhere. Single pass. Tentative version only.
Phase III
Include exit complexes, to a fixed point
Removed from 𝒞₃ but collected into 𝒞₋₃ and returned. Tentative version only.
Phase IV
Exclude terminal strong linkage classes
Buys the feeding property. In the tentative version the non-terminal survivors become 𝒞₋₄; in Remark S2-1 this is the only step after Phase I.
Final
𝒞up = 𝒞₋₄ ∪ 𝒞₋₃  ·  or just 𝒞₋₄
The tentative version unions both collections; the Upstream Algorithm returns the Phase IV result alone.

The reference implements the tentative version; Kimonu and COCOA target Remark S2-1. Remark S2-2 asserts the two are identical in input–output, and measured seed by seed on all 33 models they are: not one complex differs (kinetic_variants/). An earlier version of this page called the remark false on iCN900. That comparison had mixed singleton sets, balanced-only linkage classes and the merge rule into the algorithm, and is retracted.

Mutual validation — the one result here that is robust

Kimonu with overlap-only merging reproduces the reference exactly: 246 non-singleton modules, largest 19, covering 583 complexes against the R stage's 246 / 19 / 583. Kimonu's default differs from that only by the four balanced-only linkage classes it adds as modules and by the Proposition S3-4 coupling merge. The upstream algorithm itself is the same in all three implementations. What separates Kimonu and COCOA efficient=false from the reference at this stage is that they implement the published S3-4 merge and the reference kinetic script merges by overlap only.

Reference defect
One, found and fixed: Phase IV wrote x[terminal == 0], indexing a vector of complex ids by a mask over every complex in the graph. R selects by position and pads with NA. 352 NAs per run on iCN900, which then propagate into the overlap merge and fuse the partition into a single 626-complex blob. The comment on the line states the intent: terminal[x].
Kimonu deviations
Two, both measured across the 33. The outer iteration loop in kinetic_modules changes the partition on 0 of 33: inert on this benchmark, to be documented or removed. Phase IV tests succ[v] - c against the whole network where Remark S2-1 reads as terminal classes of G𝒞₋₄; switching to the reduced graph would change 32 of 33 partitions and most giants (iJB785 22 → 20, iAF1260b 96 → 93, iAM_P* 100 → 98). Kept as is, deliberately: an upstream set needs every complex to keep a path to 𝒞 \ 𝒞up, which full-graph terminality guarantees. Both go in Methods.

The giant is 19 in all three, and the terminal content agrees too — 0 / 8 / 8, the 8 being the balanced linkage-class modules all three implementations add by design. An earlier version of this page reported COCOA retaining 113 terminal complexes here; that was an index-space error in the comparison (Kimonu-JSON indices against CRN-space terminality, off by one above the zero complex), not a COCOA behaviour. Fed Kimonu's exact concordance partition directly, COCOA's kinetic stage returns 250 / 19 / 591 / 8 at both efficient settings — identical to Kimonu once the complex bijection is complete.

The large module-count gaps between Kimonu and the reference — 135 vs 1905 on iJB785, 296 vs 1597 on iSynCJ816, giants unchanged — are exactly the weak linkage classes composed entirely of balanced complexes (1770 and 1301), which Kimonu, the reference's R code and COCOA all add as modules. Kimonu's "8 deviant terminal complexes" on iCN900 are four of those classes. Not a discrepancy.

Stage 4

ACR and ACRR

reference column on the 4 landed final models
Definition
ACR ⟺ ei ∈ im(YΔ) ⟺ a zero row of L = ker(YΔᵀ); ACRR ⟺ two equal rows.
Numbers
acr, acrr, acr_free, acrr_free
Free counts
"Free" excludes the E_1, E_2… enzyme pseudo-metabolites introduced by the elementary-step split. Both prior papers report free counts, so these are the comparable ones.
Blocked on
The reference's ACR lives in a second R script, Get_excel_tables_kinetic_modules.R, which loads a stoichiometric_coupling/*.mat produced by F2C2('glpk', network). F2C2 is not in the tree.
Inputs
Coupling matrices generated exactly from the nullspace for all 11 final models (identical to shipped F2C2 on iCN900; ours finds 4 reactions F2C2 missed on each iIS312 variant). The final .mat files carry metabolite names; the fixed R kinetic code is the fork's. Chain: reference_final/acr/run_chain.sh, repeated as each exhaustive run lands.
First numbers
On the four landed final models (iIS312, Amastigote, Epimastigote, Trypomastigote): reference ACR 0, ACRR 1 / 1 / 1 / 3 pairs, giants 9 / 9 / 9 / 11 — equal to Kimonu's giants. Kimonu ACRR 9 / 9 / 9 / 11 (free 4 / 5 / 4 / 1). Every reference ACRR pair is in Kimonu's set by name, 4 of 4. Expected — the reference's criterion is combinatorial (two complexes in a module differing in exactly one species, Corollary S2-10), a sufficient condition; Kimonu's kernel test ei ∈ im(YΔ) is necessary and sufficient, so it finds the rest.
Reading its tables
OverviewTable[15] = 1 means exactly one ACRR pair, not none — the empty case never enters that branch — and write.table emits a single pair as a two-row column.

The runtime story is an inversion, not a ranking

The reference spends essentially 100% of its time in concordance — balanced takes 0.003–0.022 h against 3.7–138 h for the pairwise LP. Kimonu's exact concordance is nearly free, so its dominant stage is the kinetic graph traversal: 64% kinetic, 32% concordance, 4% ACR, and kinetic dominates on all 33 models. F5 should carry a stacked-stage panel showing that, because it explains the speedup rather than just asserting it.

The reference exists on 11 models and cannot be made to exist on 33, so a three-way figure across the full set is not available. The shape that works: main text carries Kimonu vs COCOA across 33 models; supplementary carries the three-way comparison on the 11 with a sampled reference at three seeds and an exhaustive reference where it finished.
